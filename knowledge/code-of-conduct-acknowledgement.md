# Employee Code of Conduct — Acknowledgement

## Overview
The Stemz Employee Code of Conduct sets out behavioural standards expected of every Stemz employee. Every employee is briefed on the Code at joining, reads it, and signs an acknowledgement form to certify agreement with the principles contained within it. The employee is given a copy of the Code to retain for their reference. Adherence to all standards documented in the full Code is mandatory. The full Code of Conduct is a separate document maintained by HR — this acknowledgement is a written commitment to comply with it.

## Employee Briefing on Code of Conduct
Every employee is briefed on the Company's Employee Conduct Standards at joining. By signing the acknowledgement form, the employee confirms that they have been briefed, have read the Employee Code of Conduct, and understand it.

## Agreement to Comply
The employee certifies agreement with the principles contained in the Employee Code of Conduct and undertakes to adhere to all standards contained within it.

## Employee Retains Copy
Every employee is given a copy of the Employee Code of Conduct to retain for their reference and information.

## Note on Full Code Content
The full Employee Code of Conduct is a separate document maintained by HR. The acknowledgement is a written commitment to comply with the standards documented in that full Code.
